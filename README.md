# R Projects: Applied Statistical Computing

Coursework in applied statistical computing and multivariate methods, including R analyses, reports, data files, and Shiny applications.

## Overview

The repository is organized by course week and assessment:

- `Week 1` through `Week 13` — weekly exercises and applications.
- `Exam 1` and `Take-Home Exam 1` — assessment materials.
- `Week 10 - Project One` — project report, source R Markdown, and data.
- `Final_Project` — final report, R Markdown source, PDF, and `app.R`.
- `Week 11`, `Week 12`, `week_12`, and `week_13` — additional R and Shiny work.

Topics represented by the files include exploratory data analysis, data manipulation, visualization, principal component analysis, hypothesis testing, and predictive analysis.

## Usage

Open the `.R`, `.Rmd`, and Shiny application files in an R environment. The repository contains source files and accompanying data, but no root installation manifest or automated test command.

## Academic context

These files are course materials and student work. Dataset and upstream report attribution should be preserved when reusing individual analyses.
